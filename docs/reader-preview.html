The shape of an argument

A short demonstration of scholarly reading, not a published edition.

Some ideas become clearer when the page grows quieter. A well-set document gives the argument room to unfold: each paragraph has a comfortable measure, quotations are easy to distinguish, and the mathematics remains legible without asking the reader to zoom out.

This sample illustrates the typography proposed for Press—a restrained reading surface built around semantic HTML, durable section links, and the conventions of mathematical writing.1

§ 1 — A small invariant ¶

Let S be a nonempty set and let f: S → S be a map. A point that stays where it is under f offers a simple illustration of an invariant.

Definition 1 — Fixed point ¶

We call x ∈ S a fixed point of f when f(x) = x. The definition does not depend on how we choose to describe the elements of S.

Theorem 1 — Identity preserves every point ¶

For the identity map, every point is fixed:

∀x∈S,idS(x)=x.

Proof ¶

By definition, the identity map sends each element to itself. Therefore the fixed-point condition holds for every x ∈ S. □

§ 2 — Quotations, tables, and code ¶

The purpose of careful typesetting is not decoration. It is to help the reader follow the argument without distraction.

An identifier such as fixed_points stays distinct in running text without an intrusive badge. A code block gets its own differentiated surface:

def fixed_points(items, function):
    return [x for x in items if function(x) == x]
